# 💸 Expense Tracker 2.0

A simple command-line expense tracker built with Python to practice object-oriented programming (OOP), user input handling, and exception handling.

## ✨ Features

- ➕ Add a new expense with an item name, cost, category, and description
- 📋 View all recorded expenses
- 🧮 Calculate total expenses
- 🛡️ Handle invalid input and prevent negative expense amounts
- 💻 Interactive command-line menu

## 🛠️ Technologies Used

- **Python 3**
- Object-Oriented Programming (OOP)
- Lists and loops
- Exception handling

## 🚀 Getting Started

### Prerequisites

Install Python 3 on your computer.

### Run the project

1. Clone this repository:

   ```bash
   git clone https://github.com/uhsadiaa-dev/Expense_Tracker2.0.git
   ```

2. Open the project folder:

   ```bash
   cd Expense-Tracker
   ```

3. Run the program (replace `main.py` with your actual Python filename if needed):

   ```bash
   python main.py
   ```

## 📸 How It Works

Run the program and use the menu to add expenses, view your recorded expenses, calculate your total spending, or exit.
